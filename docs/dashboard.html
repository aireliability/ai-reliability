Budget enforcement applies to configured provider calls routed through the AI Reliability gate. Direct provider calls outside the gate are not in enforcement scope.

How to read this dashboard

  • Healthy means the latest maintenance run matched the active eval spec for outputs, tool calls, actions, and routed-call budget rules.
  • At risk or failed means one or more checks deviated from the customer-defined source of truth, including budget blocks on routed calls.
  • Deploy gate can fail CI/CD when blocking failures or misconfiguration are present (npm run gate:release).
